# Known Limitations – Shipcube Email AI POC

- Fine-tuning dataset is limited in size and diversity
- Model responses are generic and inconsistent across similar queries
- Hallucinations observed for longer or complex emails
- No strict JSON or schema enforcement
- Latency and memory usage not suitable for real-time email automation
- High risk of incorrect or unsafe customer replies
- Not suitable for production deployment without human review

Conclusion: This implementation remains a technical proof-of-concept only.
